# Changelog

Все заметные изменения проекта документируются в этом файле.

## [0.0.1]

Первый публичный выпуск JexFold.

- Обратимая перепаковка JPEG в JPEG XL с обязательным побайтовым контролем восстановления.
- Пакетная обработка папок, пауза и отмена.
- Установщики для Windows, macOS и Linux со встроенными `cjxl` и `djxl`.
- Локальная обработка без загрузки фотографий в сеть.
